{{/* Site-level additions to Blowfish, loaded through the theme's extend-footer hook (themes/blowfish/layouts/partials/footer.html). Two behaviours the theme does not provide: 1. A focus trap for the mobile menu. The dialog declares role="dialog" aria-modal="true", but it is driven entirely by a CSS checkbox, so Tab walks straight out of it into the page behind — which the overlay covers at 97% opacity. menu-a11y.js already handles Escape, aria-expanded and the scroll lock; only containment is missing. 2. An empty state for search. On a query with no matches the theme empties #search-results and shows nothing at all, which is indistinguishable from a broken search. The theme's own scripts are bundled with `defer`, so this runs on DOMContentLoaded to be sure they have executed first. Styling uses only utility classes the theme already emits (search.js builds result rows from them) — Blowfish ships a precompiled, frozen Tailwind build, so classes it does not already use would not exist. */}}
